# Dapper Den walkthrough

A narrated walkthrough of the whole store. It starts with what the audit found, then follows one shopper from the homepage to a placed order, the receipt email and order tracking, and ends with how the rebuild would be measured.

## About the recording

The walkthrough was recorded against the store's real code with a demo database, so no test orders reached the live store. Nothing in it is a mock-up. A lime outline marks whatever the narrator is describing.

The narration is an AI-generated Indian English voice, and the on-screen captions match it line by line.
