| File | Use |
|---|---|
| `dapperden-logo-on-dark.png` | Wordmark for dark backgrounds (the site, emails) |
| `dapperden-logo.png` | Wordmark for light backgrounds: "DEN" sits on a lime block so it stays legible |

## Colours

| Name | Hex | Use |
|---|---|---|
| Ink | `#0a0a0b` | Page background |
| Card | `#131316` | Panels and cards |
| Line | `#2a2a30` | Borders and dividers |
| Lime | `#c6ff3d` | The accent: "DEN", buttons, prices, highlights |
| Magenta | `#ff2fb0` | Rare second accent: discount tags, errors |
| Soft white | `#c9c9cf` | Body text on dark |

## Type

- **Anton** for headlines, always uppercase ("WEAR IT LIKE YOU MEAN IT").
- **Space Grotesk** for buttons, labels and prices.
- **Inter** for body text.

## Voice

Confident, short and fan-first. Talk like the customer's friend who knows streetwear: *"Your drip is locked in."* *"Wear it like you mean it."* State the promises plainly: free shipping over ₹1,499, COD, 15-day returns.
